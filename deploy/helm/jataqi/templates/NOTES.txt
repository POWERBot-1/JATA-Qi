JATA Qi has been deployed!

1. Wait for the pod to become ready:
   kubectl rollout status statefulset/{{ .Release.Name }} -n {{ .Release.Namespace }}

2. Forward the gateway port:
   kubectl port-forward svc/{{ .Release.Name }} {{ .Values.service.port }}:{{ .Values.service.port }} -n {{ .Release.Namespace }}

3. Check health:
   curl http://127.0.0.1:{{ .Values.service.port }}/health
   curl http://127.0.0.1:{{ .Values.service.port }}/readyz

- Transport: {{ if .Values.jataqi.tls.enabled }}HTTPS (TLS){{ else }}HTTP (set jataqi.tls.enabled to terminate TLS){{ end }}
